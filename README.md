### What I work with

- **Agents & LLMs:** LangGraph (state graphs, tool loops, `interrupt`, checkpointers, long-term memory) · LangChain · MCP servers · function calling · multi-agent workflows · human-in-the-loop
- **Models:** Gemini · Hugging Face · Ollama (local models) · OpenRouter
- **Retrieval:** RAG · agentic RAG · pgvector · PostgreSQL full-text search · hybrid search · reciprocal rank fusion (RRF) · query rewriting

- **Data science & ML:** k-means · PCA · logistic regression · time series · A/B testing · Monte Carlo VaR
- **Reinforcement learning:** Q-learning · PPO
- **Multimodal:** vision agents (Gemini)
